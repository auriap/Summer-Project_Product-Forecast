# Summer-Project_Product-Forecast

## Overview
This project is designed to create **dummy sales data** and forecast product sales for three Cisco products over the next four quarters. It uses Python to automatically generate realistic data for key features such as product category, sales, pricing, promotions, and regional performance. The generated data simulates real-world scenarios and can be used for machine learning models, data analysis, or educational purposes.

This project is part of a learning exercise to understand:
- Data preparation and generation.
- Exploratory Data Analysis (EDA).
- Machine learning for sales forecasting.
- Using GitHub for version control and project documentation.
